# CasimirRFM

CasimirRFM is a Mathematica package for the study of compactifications on Riemann-flat manifolds (RFMs) and the computation of one-loop Casimir energies in higher-dimensional field theories and supergravity models. The package provides: 

- Construction and analysis of finite groups defining RFMs; computation of invariant metrics, cohomology forms, and spin structures. 
- Efficient numerical evaluation of lattice sums using Ewald summation; computation of Casimir potentials and Casimir energy densities. 
- Evaluation of Lorentz-group traces in graviton, p-form, spinor and Rarita--Schwinger representations.
